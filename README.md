# ML-Customer-Churn-Prediction
## Project Overview
This project uses Machine Learning to predict which customers are likely to cancel a subscription service (churn). By identifying high-risk customers, a business can intervene with retention offers.

## Technical Stack
*   **Language:** Python
*   **Libraries:** Pandas, Scikit-Learn
*   **Concepts Covered:** Classification models (Random Forest, Logistic Regression), Feature Engineering, and Model Evaluation (F1-Score, ROC Curves).
